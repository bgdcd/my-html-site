# 密铺宇宙 · AI智能教学中枢

## 当前版本
第一阶段：赛博朋克宇宙风格的统一入口与AI交互前端。

## 已完成
- 独立入口页：深紫星空、轨道行星、六个AI智能体入口。
- 原版密铺实验室通过相对路径打开：`../密铺实验室_自定义多边形蓝点修正版7.html`。没有修改原实验室文件。
- AI学伴、几何预言家、反向挑战官、几何创意助手、作品顾问：接入OpenAI兼容的 `/chat/completions` 接口。
- 空间视觉诊断：上传图片并调用支持图像输入的视觉模型。
- API密钥仅放在当前浏览器会话的 sessionStorage，不写入仓库文件。
- 教师/学生身份切换、房间码和WebSocket连接入口。

## 需要部署配置后才能启用的能力
1. **真实AI推理**：在“系统配置”中填写模型服务的Base URL、模型ID和API Key。生产课堂建议改用自有后端代理，避免把长期密钥分发到学生平板。
2. **跨设备课堂同步**：需要一个可用的WebSocket服务端。前端发送 `{type:"join", role, room}`；接收 `{type:"classroom-event", payload}`。仅填房间码不能自动实现跨设备同步。
3. **原投票入口**：目前仓库根目录文件清单未发现独立投票页面。系统提供原投票网址绑定入口，不重做、不替换原投票逻辑；拿到原投票地址后即可绑定。

## 发布
将本目录发布到静态网站后，入口为 `/ai-tessellation-hub/`。原实验室文件须继续保留在仓库根目录，确保相对路径有效。

## 教学安全边界
- AI给出的密铺预测不是数学证明；学生仍须通过拼摆、角度计算和对应边关系验证。
- 图像诊断仅作为辅助观察，不能把照片透视误差或模型猜测当成确定结论。
- 不要把生产环境长期API密钥写进前端代码或提交到GitHub。
